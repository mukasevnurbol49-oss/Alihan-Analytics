# SQL-анализ

Скрипты предназначены для PostgreSQL 14+.

1. Запустите `schema.sql`.
2. Импортируйте `../data/sales_data.csv` в таблицу `sales`.
3. Выполните `validation_queries.sql` и сверьте контрольные показатели.
4. Запускайте запросы из `analysis_queries.sql` по разделам.

После импорта должно быть 1 000 строк, 442 510 380 ₸ выручки и 31 466 проданных единиц. Поле `sale_id` создаётся автоматически и не включается в импорт CSV.
