# Словарь данных

| Поле | Тип | Описание |
|---|---|---|
| Date / `order_date` | Дата | Дата продажи |
| Branch / `branch` | Текст | Филиал |
| Manager / `manager` | Текст | Менеджер |
| Customer / `customer` | Текст | Условный клиент |
| Product / `product` | Текст | Товар |
| Category / `category` | Текст | Категория товара |
| Quantity / `quantity` | Целое число | Количество единиц |
| Unit Price / `unit_price` | Число | Цена единицы в тенге |
| Revenue / `revenue` | Число | Quantity × Unit Price |
| Payment Method / `payment_method` | Текст | Способ оплаты |
| Month | Текст | Расчётный месяц в Excel |

Одна строка соответствует одной операции и считается одним заказом. Контрольные показатели: 1 000 строк, 442 510 380 ₸ выручки, 31 466 единиц, период 2026-01-01 — 2026-12-30.
